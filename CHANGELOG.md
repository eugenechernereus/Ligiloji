# Changelog

All notable changes to Ligiloji are documented in this file.

The project is currently under active development, so the format
and release process may evolve over time.

## [v0.2.2] - 2026-08-31

### Added

- Fixed the encryption of large data
- Replaced temporary auto-save with manual saving

## [v0.2.1] - 2026-08-28

### Added

- Hide scroll-buttons in textarea
- Fixed md
- Adjusted text notes

## [v0.2.0] - 2026-08-27

### Added

- MarkDown-editor in notes

## [v0.1.3] - 2026-08-26

### Added

- Minor interface changes
- Function of unfolding long notes

## [v0.1.2] - 2026-08-20

### Added

- Adjusted sizes and fonts
- Temporary auto‑saving of changes

### Added

- Initial public release of Ligiloji
- Single-file HTML application
- Sections
- Categories
- Link management
- Search
- JSON export
- JSON import
- HTML saving
- Silver visual theme
- Gold visual theme
- Trash handling
- Password-protected data support
- Portable HTML-based data storage
- Copyright notice
- Scroll-buttons

### Project

- Published source code repository
- Added Git version tag
- Established proprietary licensing
- Added project documentation
